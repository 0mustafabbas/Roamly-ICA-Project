# Roamly - Smart Trip Planner (PD1 Summary)

## Concept & Purpose
Roamly is a travel-planning web application that helps users plan trips, organize daily schedules, and estimate overall travel costs in one place[cite: 71].

## Target Users & Problem Solved
- Target Users: University students and young adults, budget travelers, groups of friends planning trips, and travelers organizing travel expenses[cite: 71].
- Problem & Solution: Travelers often have to jump across multiple websites to research destinations, activities, schedules, and costs[cite: 71]. Roamly brings destination selection, activity planning, itineraries, and cost estimation into one platform[cite: 71].
